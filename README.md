# clueless releases

Installers for **clueless**, Interval's call assistant. The source code is private; this repo only hosts releases.

**[Download the latest release](https://github.com/interval-ai/clueless-releases/releases/latest)**

- **Mac:** `clueless-<version>-arm64.dmg` for Apple Silicon (M1 and later), `clueless-<version>.dmg` for Intel. Open it and drag clueless to Applications.
- **Windows:** `clueless Setup <version>.exe`. Windows may say it protected your PC; choose **More info → Run anyway**.

Then:

1. Sign in with your `@interval-ai.com` email. You'll get a 6-digit code. An admin has to add you to the team first.
2. In **Settings → Answers**, add your OpenAI API key (and Groq and TypeSafe keys for automatic answers).
3. Click **Start** and allow microphone (and, on Mac, screen and system audio) access when asked.

On Mac, clueless updates itself: new versions download in the background and install the next time you quit. On Windows, download and run the new installer from this page when a new version is announced.
